**计划周期：2026 年 10 月—2028 年 3 月**

**当前进度：OpenArm Stage 4 — MoveIt2**

**最终目标：** 具备机器人视觉、C++ 系统工程、机器人操作学习、仿真与实机部署能力，完成两个可以独立展示、复现和深入讨论的技术项目。

# Part A：OpenArm 经典机器人系统

**项目定位：机器人感知、运动规划、双臂操作、Sim-to-Sim。**

技术栈：

- ROS2 Jazzy / C++ / Python
- ros2_control / MoveIt2 / MTC
- Gazebo / MuJoCo
- OpenCV / GDRNPP / 6D Pose
- TF2 / 机器人运动学 / 控制

## Stage 0–3：基础系统

- Stage 0：开发环境、Workspace、colcon
- Stage 1：ROS2 Node、Topic、Service、Action
- Stage 2：URDF、Xacro、TF2、机器人模型
- Stage 3：ros2_control、Controller、Hardware Interface

**要求：** 后续按需复习，不再单独扩展 ROS2 理论。

## Stage 4：MoveIt2 运动规划

**学习内容**

- FK / IK、Robot State、Planning Group
- PlanningScene、碰撞检测
- OMPL、RRTConnect 基本原理
- 关节空间与笛卡尔空间目标
- 轨迹规划、执行、失败诊断

**实践任务**

1. 使用 RViz 完成左右机械臂运动规划。
2. 使用 C++ 编写最小 MoveIt2 规划执行程序。
3. 测试不可达目标、碰撞及关节限制等失败场景。

**验收：** 不依赖 RViz 手动操作，能够通过程序设置目标、规划轨迹、执行并验证结果。

## Stage 5：MoveIt Task Constructor

**学习内容**

- MTC 的 Stage、Container 和 Solution
- GenerateGraspPose、ComputeIK
- MoveRelative、MoveTo、Connect
- Attach / Detach Object
- 抓取任务规划与失败分析

**实践任务**

1. 跑通已有 Fake Pick & Place。
2. 独立编写简化版 MTC 抓取程序。
3. 修改抓取姿态、接近距离和物体位置。
4. 实现双臂分别抓取目标的基本流程。

**验收：** 完成能够程序化执行的 Pick & Place，并理解各个 Stage 的作用。

## Stage 6：Gazebo 物理仿真

**学习内容**

- Gazebo 物理引擎与场景建模
- ROS2 和仿真系统的通信
- ros2_control 仿真接口
- RGB-D 相机与 CameraInfo
- 接触、重力、碰撞和执行误差

**实践任务**

1. 将 OpenArm 放入物理仿真环境。
2. 配置机器人控制接口。
3. 实现单臂抓取和放置。
4. 加入 RGB-D 相机。

**验收：** 在 Gazebo 内完成一次真实物理仿真意义上的抓放操作，而不仅是 Fake Hardware 关节运动。

## Stage 7：感知与规划接口

**学习内容**

- RGB-D 图像与三维点恢复
- 坐标变换与相机外参
- PoseStamped、时间戳
- 感知模块与规划模块解耦
- PlanningScene 动态更新

**实践任务**

1. 使用仿真真值 Pose 验证下游链路。
2. 自行编写 Object Pose Publisher。
3. 将目标位姿转换到机器人基座坐标系。
4. 根据目标位姿生成抓取任务。

**验收：** 外部输入一个目标位姿，机器人能自动进行规划和抓取。

## Stage 8：接入 GDRNPP 6D Pose

**学习内容**

- 6D Pose 模型输入输出
- 旋转矩阵、四元数、SE(3)
- 相机坐标系与机器人坐标系
- 手眼标定基础
- 位姿噪声、时延和多帧滤波

**实践任务**

1. 将已有 GDRNPP 封装为 ROS2 感知节点。
2. 输出目标物体的 6D Pose。
3. 使用 TF2 完成坐标转换。
4. 将估计结果接入 MoveIt2 / MTC。
5. 比较真值 Pose 与模型估计 Pose 下的任务表现。

**验收：** 完成视觉引导抓取，并统计位姿估计误差与抓取成功率。

## Stage 9：双臂精确操作

**核心任务：双臂分别抓取两个物体，完成相对位姿对齐。**

**学习内容**

- 双臂运动学与坐标变换
- Relative Pose
- 双臂协调运动规划
- 物体与夹爪的约束关系
- Visual Servoing 基础
- 接触、柔顺控制基础

**实践任务**

1. 双臂分别抓取两个物体。
2. 计算两个物体的目标相对位姿。
3. 完成空间位置和姿态对齐。
4. 加入视觉闭环调整。
5. 尝试简单的宽容差对接任务。

**验收：** 完成双臂持物对齐 Demo，报告位置、角度误差及成功率。

**范围控制：** 精密插接作为可选挑战。若双臂任务耗时超出预期，先用单臂持物、固定目标对接完成闭环。

## Stage 10：MuJoCo 与 Sim-to-Sim（OpenArm 收尾）

**学习内容**

- MuJoCo 模型格式和动力学参数
- 关节驱动、执行器与反馈控制
- 物理参数和控制频率匹配
- Gazebo 与 MuJoCo 的差异
- 跨仿真环境的控制策略迁移

**实践任务**

1. 建立 OpenArm MuJoCo 模型。
2. 校验关节轴、运动学、限位、质量及惯量。
3. 统一 Gazebo 和 MuJoCo 的控制输入与状态定义。
4. 在两个环境中运行相同的闭环控制逻辑。
5. 比较关节跟踪误差、末端误差和任务成功率。
6. 分析动力学与接触参数变化的影响。

**验收：**

- 同一控制方案能在两个仿真器中运行。
- 具有可复现的对比实验。
- 有定量误差分析。
- 完成 OpenArm 项目的 README、技术报告和视频演示。

注意：只把轨迹从一个仿真器复制到另一个仿真器，属于初步兼容性测试；最终应包含真正的闭环控制迁移实验。

**至此结束 OpenArm 主线，不在这个仓库里继续叠加 VLA、RL 等功能。**

# Part B：Rebot 实体机器人与具身智能

**项目定位：遥操作、机器人学习、VLA、强化学习、Sim-to-Real。**

技术栈按实际硬件兼容性选择：

- Python / PyTorch / C++
- Rebot 硬件控制接口
- MuJoCo / 机器人仿真
- LeRobot
- Behavior Cloning / ACT
- Diffusion Policy / VLA
- Reinforcement Learning

## Rebot Stage 0：硬件选型与准备

**学习内容**

- 机械臂自由度、负载、精度
- 关节控制与末端控制接口
- 位置控制、速度控制、力矩控制的区别
- 状态反馈频率与控制频率
- 相机、夹爪、计算资源
- 急停、限位和安全机制

**实践任务**

1. 核实 Rebot SDK 和控制接口。
2. 确认仿真模型是否可用。
3. 评估遥操作和数据采集方案。
4. 确认硬件是否满足后续策略部署需求。

**验收：** 完成硬件与软件兼容性检查，再决定最终采购配置。

## Rebot Stage 1：实机控制

**学习内容**

- 正逆运动学
- 关节状态读取
- 末端位姿控制
- 控制周期与通信延迟
- 相机及机器人标定
- 实机安全控制

**实践任务**

1. 读取真实机械臂状态。
2. 执行基本关节运动。
3. 实现简单末端轨迹控制。
4. 建立仿真与实机的一致状态定义。
5. 完成一个无需学习策略的真实操作任务。

**验收：** 实机稳定运行，具备日志、限位、急停和失败恢复机制。

## Rebot Stage 2：遥操作与数据采集

**学习内容**

- Leader-Follower / Teleoperation
- Observation / Action 定义
- Action Space 与控制频率
- 数据同步与时间戳
- 相机标定和多模态数据采集
- 机器人数据集格式
- 数据清洗和质量评估

**实践任务**

1. 实现或接入遥操作接口。
2. 同步记录图像、关节状态与动作。
3. 采集抓取、移动、放置任务轨迹。
4. 建立训练、验证、测试数据划分。
5. 设计示教数据质量检查工具。

**验收：** 建立可复现的真实机器人操作数据集。

## Rebot Stage 3：模仿学习基础

**学习内容**

- Behavior Cloning
- Behavior Cloning 的分布偏移问题
- Action Chunking
- ACT 架构
- 数据归一化
- 离线评估与闭环评估

**实践任务**

1. 训练一个简单 BC 基线。
2. 训练 ACT 策略。
3. 比较不同数据量和动作块长度。
4. 在仿真或受控实机任务中评估。
5. 分析失败案例。

**验收：** 用示教数据训练出的策略能够独立执行基础机器人任务。

## Rebot Stage 4：VLA 模型

**学习内容**

- VLM 与 VLA 的区别
- 语言条件机器人操作
- 视觉、语言、机器人状态的输入编码
- Action Token / Continuous Action
- π₀、SmolVLA 等代表性架构
- VLA 微调与推理部署
- 机器人硬件 Action Space 适配

**实践任务**

1. 阅读一个 VLA 的核心架构。
2. 运行公开预训练模型的示例。
3. 将个人数据转换为模型支持的格式。
4. 完成一次微调实验。
5. 尝试在 Rebot 上执行指定任务。
6. 比较 ACT 与 VLA 的任务表现。

**验收：** 实现一个有语言或视觉指令条件的机器人操作 Demo，并报告泛化测试结果。

## Rebot Stage 5：强化学习

**学习内容**

- MDP 与机器人控制
- Reward Design
- PPO / SAC 基础
- Actor-Critic
- Domain Randomization
- Residual RL
- 策略稳定性与样本效率

**实践任务**

1. 在 MuJoCo 建立简单操作任务。
2. 定义 Observation、Action、Reward。
3. 完成一次完整 RL 训练。
4. 分析训练曲线。
5. 比较不同初始状态和扰动。
6. 尝试学习接触调整或残差控制策略。

**验收：** 在仿真环境中训练出能够稳定完成任务的策略。

不要求必须用 RL 解决完整的复杂抓取任务，优先选择可验证的小任务。

## Rebot Stage 6：Sim-to-Real

**学习内容**

- Reality Gap
- 动力学参数辨识
- Domain Randomization
- Observation Noise
- Action Latency
- 控制频率与策略部署
- 策略安全约束

**实践任务**

1. 对齐 MuJoCo 和 Rebot 的运动学及动作接口。
2. 对仿真环境进行参数随机化。
3. 在仿真中验证策略鲁棒性。
4. 将通过安全测试的策略迁移到实机。
5. 统计真实成功率。
6. 分析仿真与真实执行差异。

**验收：** 完成一个具有定量实验结果的 Sim-to-Real 操作任务。

## Rebot Stage 7：综合实验与项目收尾

**目标：** 对同一机器人操作任务进行多种方案比较。

建议比较：

- 传统规划与控制基线
- BC / ACT
- VLA
- RL 或混合策略（如有条件）

**评价指标**

- 任务成功率
- 对初始状态变化的鲁棒性
- 对物体位置变化的适应能力
- 执行耗时
- 推理延迟
- 数据采集与训练成本
- 实机失败模式

**最终成果**

1. 完整 GitHub 项目。
2. 机器人操作视频。
3. 系统架构图。
4. 技术实验报告。
5. 可以用于技术面试的项目总结。

# Part E：优先级与止损机制

## P0：必须完成

- OpenArm 运动规划与物理仿真
- 视觉引导操作闭环
- Gazebo → MuJoCo Sim-to-Sim
- 扎实的 C++ 工程与算法能力

## P1：优先争取

- 双臂物体对齐
- Rebot 实机控制
- 遥操作与数据采集
- ACT / BC 模仿学习
- 基础 VLA 微调

## P2：时间和资源允许时进行

- 高精度接触装配
- 更复杂的 VLA 模型
- 实机强化学习相关探索
- 完整 RL Sim-to-Real
- VLA 与经典控制的混合架构

**止损原则：**

- 一个阶段长期无法完成时，先缩小任务，不盲目增加框架。
- ROS2 原理学到足以独立开发、调试与解释，不追求中间件专家级深度。
- 遇到实机安全、硬件接口或算力瓶颈时，允许先完成仿真实验。
- 每阶段至少留下可运行代码、实验记录和一段可解释的技术总结。

**最终验收标准：**

两个项目不仅能运行，还必须能回答：

1. 为什么这样设计系统？
2. 各模块输入、输出和接口是什么？

5. 如何量化性能与失败原因？
6. 如果重新设计，会怎样改进？

**最终原则：少堆技术名词，多做闭环系统；少依赖教程复现，多做独立实现；以工程结果和可验证的技术能力为目标。**
